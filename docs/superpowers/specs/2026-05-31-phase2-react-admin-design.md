# Phase 2 — React Admin UI Design

**Date:** 2026-05-31  
**Status:** Approved  
**Plugin:** smart-alt-generator (prefix `SAG_`)

---

## Goal

Replace the PHP/vanilla-JS admin UI with React (`@wordpress/components`). Scope: Settings page (Modern Cards layout) + Bulk page (Simple — same functionality). New feature: Test Connection button on Settings page.

---

## Decisions

| Decision | Choice |
|----------|--------|
| Settings page layout | Modern Cards — organized by section (AI Provider, Generation) |
| Bulk page layout | Simple — same as today (stats + progress + log), React instead of vanilla JS |
| New feature | Test Connection button — verifies OpenAI API key |
| Data approach | Two separate React entry points + custom REST endpoints for settings |
| PHP settings API | Kept for registration only; saving moves to REST |

## REST API — New Endpoints

### GET `/smart-alt/v1/settings`

Returns all 4 plugin options as JSON.

**Permission:** `manage_options`

**Response:**
```json
{
  "sag_openai_api_key": "sk-proj-...",
  "sag_model": "gpt-4o-mini",
  "sag_language": "auto",
  "sag_auto_generate": false
}
```

Note: API key is returned as-is (only admins can call this endpoint).

---

### POST `/smart-alt/v1/settings`

Validates and saves options.

**Permission:** `manage_options`

**Request body** (any subset of fields):
```json
{
  "sag_openai_api_key": "sk-proj-...",
  "sag_model": "gpt-4o-mini",
  "sag_language": "auto",
  "sag_auto_generate": true
}
```

**Validation:**
- `sag_model`: must be `gpt-4o-mini` or `gpt-4o` (same whitelist as `SAG_Settings::sanitize_model`)
- `sag_language`: `sanitize_text_field`
- `sag_openai_api_key`: `sanitize_text_field`
- `sag_auto_generate`: cast to bool

**Response on success:**
```json
{ "saved": true }
```

**Response on error:**
```json
{ "code": "sag_invalid_model", "message": "Invalid model.", "data": { "status": 400 } }
```

---

### GET `/smart-alt/v1/test`

Tests the OpenAI API key by making a minimal chat completion request (`max_tokens: 1`). Does NOT save anything. Uses the currently saved `sag_openai_api_key`.

**Permission:** `upload_files`

**Response on success:**
```json
{ "ok": true, "model": "gpt-4o-mini" }
```

**Response on failure:**
```json
WP_Error → { "code": "sag_test_failed", "message": "Incorrect API key..." }
```

## Settings Page

### Component tree

```
<SettingsApp>
  <ConnectorsNotice />          ← shown only when hasConnector=true (WP 7.0+)
  <ProviderCard>                ← hidden when hasConnector=true
    <TestConnectionButton />
  </ProviderCard>
  <GenerationCard />
  <SaveFooter />
</SettingsApp>
```

### Components

**`<SettingsApp>`**  
Root component. On mount: calls `GET /smart-alt/v1/settings`, populates state. Passes `settings`, `setSettings`, `onSave` down as props.

**`<ConnectorsNotice>`**  
Green notice bar. Rendered only when `window.sagSettingsData.hasConnector === true`. Data injected via `wp_localize_script`.

**`<ProviderCard>`**  
Card "AI Provider". Contains:
- `TextControl` for API key (type=password, with show/hide toggle button)
- `SelectControl` for model (`gpt-4o-mini` / `gpt-4o`)
- `<TestConnectionButton />`

Hidden entirely when `hasConnector=true`.

**`<TestConnectionButton>`**  
Button ("⚡ Test Connection") inside ProviderCard. On click: calls `GET /smart-alt/v1/test`. Shows spinner while loading. After response: inline badge — `✓ Connection successful` (green) or `✗ <error message>` (red). Badge clears when the API key field changes.

**`<GenerationCard>`**  
Card "Generation". Contains:
- `ToggleControl` for auto-generate on upload
- `TextControl` for language (placeholder: "auto")

**`<SaveFooter>`**  
Sticky card-footer. Contains:
- "Save Settings" `Button` (variant="primary")
- Inline notice: `✓ Settings saved` (green) or error message (red) — appears after save attempt, auto-clears after 3 seconds

### Data injected via `wp_localize_script`

```php
wp_localize_script( 'sag-admin-settings', 'sagSettingsData', [
    'hasConnector' => function_exists( 'wp_ai_client' ),
    'nonce'        => wp_create_nonce( 'wp_rest' ),
    'restBase'     => rest_url( 'smart-alt/v1' ),
] );
```

Settings themselves are loaded via REST (not via `wp_localize_script`) to avoid duplication.

## Bulk Page

### Component tree

```
<BulkApp>
  <StatBar />
  <ProgressBar />
  <BulkControls />
  <LogList />
</BulkApp>
```

### Components

**`<BulkApp>`**  
Root. Receives `imageIds[]` and `nonce` via `window.sagBulkData` (injected by PHP). Manages state: `status` (idle | running | paused | done), `done`, `errors`, `log[]`. Runs sequential REST loop.

**`<StatBar>`**  
4 stat boxes: Total / Completed / Errors / Remaining. All derived from state, no props needed beyond the top-level state.

**`<ProgressBar>`**  
Visual progress bar + percentage + `N / total` counter. Receives `done` and `total` as props. Pure component.

**`<BulkControls>`**  
Single button with label that changes by status:
- `idle` → "Generate All" (primary)
- `running` → "Pause" (secondary)
- `paused` → "Resume" (primary)
- `done` → "✓ All done" (disabled)

**`<LogList>`**  
Scrollable list of result items. Each item: `✓`/`✗` icon + alt text (on success) or error message (on failure) + image ID. Most recent item at top. "Clear log" button in header.

### Data injected via `wp_localize_script`

```php
wp_localize_script( 'sag-admin-bulk', 'sagBulkData', [
    'imageIds' => $sag_ids,     // array of int
    'nonce'    => wp_create_nonce( 'wp_rest' ),
    'restBase' => rest_url( 'smart-alt/v1' ),
] );
```

PHP still queries images missing alt text (existing `WP_Query` logic) and passes IDs to React.

### Loop behavior

- Sequential: one `POST /smart-alt/v1/generate` at a time (same as today)
- Pause: sets a flag checked before each iteration; current request completes first
- Resume: continues from where it paused (remaining IDs)
- On error: logs the error, increments error counter, continues to next image

## Enqueueing (admin/class-sag-admin.php)

```php
// Hook for settings page bundle
add_action( 'admin_enqueue_scripts', [ $this, 'enqueue_assets' ] );

// In enqueue_assets():
if ( 'settings_page_sag-settings' === $hook ) {
    $asset = require SAG_PLUGIN_DIR . 'build/admin-settings.asset.php';
    wp_enqueue_script(
        'sag-admin-settings',
        SAG_PLUGIN_URL . 'build/admin-settings.js',
        $asset['dependencies'],
        $asset['version'],
        true
    );
    wp_localize_script( 'sag-admin-settings', 'sagSettingsData', [...] );
}

if ( 'media_page_sag-bulk' === $hook ) {
    // Run WP_Query for image IDs here (moved from PHP template)
    $asset = require SAG_PLUGIN_DIR . 'build/admin-bulk.asset.php';
    wp_enqueue_script(
        'sag-admin-bulk',
        SAG_PLUGIN_URL . 'build/admin-bulk.js',
        $asset['dependencies'],
        $asset['version'],
        true
    );
    wp_localize_script( 'sag-admin-bulk', 'sagBulkData', [...] );
}
```
